安装步骤

1 安装应用

下载 .dmg 文件后，双击打开并将 Clash Verge 拖拽到 Applications 文件夹中。

2 打开应用

在 Applications 文件夹中找到 Clash Verge 并双击打开。如果是首次打开，macOS 可能会提示"无法验证开发者"，此时需要到系统设置中允许运行。

3 允许应用运行

如果遇到安全提示，前往 系统设置 → 隐私与安全性 → 滚动到最底部点击"仍要打开"。

Homebrew 安装（可选）

如果你使用 Homebrew 包管理器，也可以通过命令行安装：

brew install --cask clash-verge-rev
下一步： 安装完成后，订阅导入、节点选择和启动代理步骤与 Windows、Linux 一致，可以直接查看通用图文使用教程。

常见问题

⚠️ 无法打开应用？

如果 macOS 阻止应用运行，请前往 系统设置 → 隐私与安全性，允许来自任何来源的应用。

⚠️ 性能问题？

如果在 M 系列芯片上运行缓慢，确保你下载的是 arm64 (Apple Silicon) 版本。
