iOS 上的代理选择

Clash Verge 本身没有 iOS 原生客户端。在 iOS 设备上，推荐使用 Shadowrocket 配合机场订阅使用。Shadowrocket 是 iOS 上知名的代理工具，支持导入常见的订阅格式。

⚠️ 重要说明： Shadowrocket 为付费软件，在中国区 App Store 售价约 ¥3.00。如果你不想付费，可以考虑使用共享 ID方式获取（即使用他人已购账号下载，但请注意账号安全风险）。

方式一：使用共享 ID 下载（免费）

如果你想免费使用 Shadowrocket，可以借用他人已购买过该应用的 Apple ID 下载。下面按照你提供的视频和图文步骤整理。

1 打开 App Store

在 iPhone 主屏幕上找到并打开 App Store。整个流程都只在 App Store 中进行，不要进入“设置”里切换账号。

图 1：先打开 App Store。

2 点击右上角头像

进入 App Store 后，点击右上角头像，进入账号页面。

图 2：点击 App Store 右上角头像。

3 退出当前 App Store 账号

在账号页面向下滑动到底部，点击“退出登录”。这里只退出 App Store 登录状态，不会退出你手机“设置”里的 iCloud 账号。

图 3：向下滑动到底部，点击退出登录。

4 使用共享 ID 登录

退出后，点击“通过 Apple ID 登录”，输入你找到的共享 ID 和密码。

图 4：点击“通过 Apple ID 登录”。

5 遇到安全验证时选择“其他选项”

如果登录时出现 Apple ID 安全验证页面，不要继续走设备验证，按图示点击“其他选项”，再根据后续提示处理。

图 5：如果出现安全验证页，优先点击“其他选项”。

6 搜索 Shadowrocket 并下载

成功登录共享 ID 后，在 App Store 搜索 shadowrocket，找到应用后点击“获取”或价格按钮下载。

图 6：搜索 shadowrocket，然后点击获取或价格按钮下载。

7 下载完成后换回自己的账号

下载完成后，立即在 App Store 中退出共享 ID，重新登录你自己的 Apple ID。Shadowrocket 安装完成后可以继续正常使用。

⚠️ 安全提示：
  • 共享 ID 仅用于 App Store 下载，切勿在“设置”中登录 iCloud，否则可能导致数据丢失或账号被锁
  • 不要修改共享 ID 的密码
  • 不建议在共享 ID 的已购项目中购买任何内购
  • 下载完成后尽快换回自己的 Apple ID

方式二：直接购买（推荐）

如果你希望支持开发者并且长期使用，建议直接购买 Shadowrocket。

  1. 打开 App Store，切换到非中国区商店（如果中国区下架了）
  2. 搜索 "Shadowrocket"
  3. 点击购买（约 $3.99 美元）

Shadowrocket 订阅配置

下载并安装 Shadowrocket 后，配置步骤与 Windows、Linux、macOS 基本一致：

1 添加订阅

打开 Shadowrocket，点击左上角"+"按钮，选择"订阅"类型。

2 粘贴订阅链接

将你的机场订阅链接粘贴到 URL 输入框中，点击完成。

3 更新并选择节点

在配置列表中长按订阅，点击"更新"。更新完成后，选择合适的节点。

4 启动代理

回到 Shadowrocket 主界面，点击顶部的开关启用代理。首次使用时会提示添加 VPN 配置，点击允许。

💡 提示： 如果你想在 iOS 上获得更好的体验，也可以考虑使用其他支持 Clash 订阅的 App，如 Surge、Quantumult X 等。

常见问题

⚠️ 共享 ID 不可用？

共享 ID 可能存在多人同时使用导致密码被改、账号被锁等情况。如果无法登录，请尝试其他共享 ID 源，或直接购买正版。

⚠️ 无法下载 App？

如果 App Store 提示"此应用不再提供"，说明该应用已从你所在地区的商店下架。此时需要切换到其他地区的 Apple ID。

⚠️ VPN 配置添加失败？

iOS 14 及以上系统需要在"设置 → 隐私与安全性"中允许 VPN 配置。如果仍然失败，重启设备后再试。
