安装方式

1 Ubuntu / Debian 系统

下载 .deb 文件后，使用以下命令安装：

sudo dpkg -i clash-verge_*.deb
sudo apt-get install -f
2 Fedora / RHEL / CentOS 系统

下载 .rpm 文件后，使用以下命令安装：

sudo rpm -i clash-verge-*.rpm
3 AppImage 便携版（适用于所有发行版）

下载 .AppImage 文件后，赋予执行权限即可运行：

chmod +x Clash.Verge-*.AppImage
./Clash.Verge-*.AppImage

使用命令行安装（可选）

如果你使用的是 Arch Linux 或其衍生发行版（如 Manjaro），可以使用 AUR 安装：

yay -S clash-verge-rev-bin

常见问题

⚠️ 依赖问题？

如果遇到依赖问题，请确保你的系统已经更新到最新状态。对于 Ubuntu/Debian 系统，运行 sudo apt update && sudo apt upgrade。

⚠️ 无法启动？

如果程序无法启动，尝试从终端运行以查看错误信息：clash-verge
